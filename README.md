## 📄 Assignment 2 (Experiment 2)
- **Objective**: Design and develop a personal Resume / Portfolio webpage using HTML5 semantic elements, robust SEO metadata, and include sections such as Personal Information, Career Objective, Education, Skills, Projects, and Contact Details.
- **Key Concepts Covered**:
  - Semantic HTML5 structure: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`.
  - Accessible navigation with ARIA label (`aria-label="Primary Navigation"`).
  - CSS Custom Properties (`--bg`, `--card`, `--text`, `--accent`).
  - Responsive box model constraints and clean typography.
- **File**: [`assignment-2/index.html`](assignment-2/index.html)

## 📝 Assignment 3 (Experiment 3)
- **Objective**: Design and develop an HTML Registration form using different input types and form elements. Apply appropriate HTML validation attributes to validate user input.
- **Key Concepts Covered**:
  - Organized `<fieldset>` sections with `<legend>` captions:
    1. *Personal Credentials*
    2. *Academic and Technical Domain*
    3. *Security and Location*
  - Comprehensive input controls:
    - Text (`type="text"`)
    - Email with pattern validation (`type="email"`)
    - Telephone (`type="tel"`)
    - Date picker (`type="date"`)
    - Radio buttons grouped by `name="gender"`
    - Dropdown menu (`<select>` & `<option>`)
    - Numeric input with ranges (`min="1" max="4"`)
    - Domain checkboxes (`type="checkbox"`)
    - URL input (`type="url"`)
    - File upload (`type="file" accept=".pdf"`)
    - Password with character constraints (`minlength="8"`)
    - Multi-line comment textarea (`<textarea>`)
  - Form submission and reset controls.
- **File**: [`assignment-3/index.html`](assignment-3/index.html)
