# webd-assignment

Laboratory experiments for Web Development by **Arman Sharma** ([@armanattrey](https://github.com/armanattrey)).

## Structure

```
webd-assignment/
├── assignment-2/
│   └── index.html       # Experiment 2: Personal Resume / Portfolio
└── assignment-3/
    └── index.html       # Experiment 3: Student Registration Portal
```

### Assignment 2 (Experiment 2)
- **Objective**: Design and develop a personal Resume/Portfolio webpage using HTML5 semantic elements, robust SEO metadata, and include sections such as Personal Information, Career Objective, Education, Skills, Projects, and Contact Details.
- **File**: [`assignment-2/index.html`](assignment-2/index.html)

### Assignment 3 (Experiment 3)
- **Objective**: Design and Develop an HTML Registration form using different input types and form elements. Apply appropriate HTML validation attributes to validate user input.
- **File**: [`assignment-3/index.html`](assignment-3/index.html)
